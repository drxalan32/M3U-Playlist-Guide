M3U Playlist Validator

Paste an M3U playlist or select a local .m3u or .m3u8 file to check its structure, entries, URLs, metadata and duplicate locations.

Privacy: validation and cleanup run locally in this browser. The tool makes no network requests and does not contact stream URLs, upload your playlist or test playback. Avoid using it on a shared device if your playlist contains private credentials.
