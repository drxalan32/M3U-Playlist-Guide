Privacy Policy

This page describes the current operation of IPTV Guide UK, a static website hosted using GitHub Pages.

Information handled by hosting

When you visit a hosted website, the hosting provider may process technical information such as IP address, browser details, requested pages and timestamps for delivery, security and service operation. Consult GitHub's Privacy Statement for details about its processing.

Forms, accounts and analytics

This website uses Google Analytics 4 (GA4) to measure page visits and interactions, including clicks to the Kemo TV website. Optional analytics is disabled by default and loads only after you select “Allow analytics” in the consent banner. If you reject optional analytics, GA4 is not loaded. Your preference is stored in this browser so the banner does not appear on every visit. You can change your choice at any time using the “Cookie preferences” control on the website. GA4 may process technical and usage information such as page views, browser/device information, approximate location and interaction events. Do not submit sensitive personal information through analytics events.

External links

Links to third-party websites, including Kemo TV and GitHub, are governed by those websites' own privacy policies and practices. Review their policies before providing personal information.

Changes

This policy may be updated if the website's features or data practices change. The latest version will be published on this page.
