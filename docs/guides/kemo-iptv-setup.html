STEP-BY-STEP SETUP

How to Set Up Kemo IPTV in Smarters Pro

This guide uses one player: Smarters Pro. For a standard Kemo account, choose Login with Xtream Codes API. You will enter the server URL, username and password supplied with your Kemo account.

Important: Smarters Pro is only the media player. It does not create an account or provide channels. Your Kemo subscription and login details are separate. Menu labels can differ slightly by device and app version.

STEP 01

Install Smarters Pro for your device

Open the official app store on your device, search for Smarters Pro, and check the app name and publisher before installing. Use the device-specific version where one is offered.

  • Android phone/tablet: Google Play Store.
  • Android TV/Google TV: Google Play Store on the television.
  • iPhone/iPad/Apple TV: Apple App Store on that device.
  • Samsung TV: Apps from Smart Hub.
  • Windows/macOS: use the publisher's official website. The publisher currently labels these desktop versions as beta.

Never install a modified APK or a file from an unknown download site. If the app is not available for your device or region, check the publisher's current compatibility information.

STEP 02

Open the app and choose Xtream Codes API

Launch Smarters Pro. Accept the app terms if prompted, then open the option to add a playlist or user. Choose Login with Xtream Codes API. On some versions, the same sign-in method may be labelled Player API.

Do not select a Stalker Portal, MAG portal, single-stream or local-media option for this standard Kemo login. Those are different connection methods.

STEP 03

Enter your Kemo account details

Complete all four fields exactly as shown in the account details Kemo sent you. The example below uses placeholders only.

  • Any Name: choose a label such as Kemo TV. This is only the profile name on your device.
  • Username: copy the username supplied with your account.
  • Password: copy the password exactly. Check capital letters and avoid extra spaces.
  • Server URL: paste the complete server address, including the http:// or https:// prefix and any port number if supplied.

Do not enter your website address or a guessed server address. Use the exact server URL supplied by Kemo. Never share your password or full login URL in a public screenshot.

STEP 04

Select Add User and wait for the playlist

Review the fields, then select Add User. Keep the app open while it connects and loads the categories included with your account. A large playlist may take a little longer.

If the app shows a login error, recheck the server URL, username and password, then ask Kemo to confirm that the account is active and the details are correct.

STEP 05

Open Live TV and choose a channel

Select Live TV, open the category you want, then choose a channel. Use the on-screen controls or remote to switch channels and enter full-screen mode. If your account includes Movies or Series, those sections appear separately.

Try more than one channel if playback does not start. If only one channel fails, note its name and contact the provider. If every category fails, check the account and connection first.

Only received an M3U link? Do not split that link into username, password and server fields. Return to the app's login choices, select the playlist/M3U URL option, give the playlist a name and paste the complete M3U link exactly as supplied. Use this alternative only if Kemo actually sent you an M3U link.

QUICK FIXES

Fix common Smarters Pro login and playback issues

Login Failed / Invalid Details

Re-copy the username and password, check capital letters, and confirm the complete Server URL. Make sure the account is active. If the error remains, ask Kemo to verify the credentials.

Account loads but channels are missing

Refresh or reload the playlist if that option is available. Check that the account plan includes the category you expect, then contact Kemo if the list still looks incomplete.

Channels keep buffering

Test your internet connection, pause other heavy downloads and try another channel. If only one channel buffers, report that channel name and the time of the issue to support.

TV guide / EPG is empty

Allow the app time to load the guide and use its refresh or update option if available. If the guide remains empty, ask Kemo whether EPG data is included and available for your account.

App is not available in your store

Check the official publisher page for your exact device and region. Do not install an APK from an unknown mirror or assume another device's app edition will work.

One channel will not play

Try a different channel and reopen the app. If other channels work, send support the affected channel or category name rather than your password.

When contacting support, share your device model, app version and the error text. Never send your password or full playlist URL in a public message.

QUICK ANSWERS

Frequently Asked Questions

Does Smarters Pro include Kemo channels?

No. Smarters Pro is a media player. Your playlist or subscription comes separately from your provider.

Which login option should I choose?

For the standard Kemo account details, choose Login with Xtream Codes API (sometimes labelled Player API). Enter the server URL, username and password supplied with your account. Use an M3U option only if Kemo specifically supplied an M3U playlist link instead.

Can I use Smarters Pro on every Smart TV?

No. App availability depends on the TV operating system, model and region. The publisher currently lists Samsung TV and marks LG as coming soon.

What if my device is not listed?

Ask Kemo which player and installation method it supports for your exact model. Do not assume that instructions for Android TV also apply to Fire TV, MAG, Formuler or Hisense.

Why does Smarters Pro show Login Failed?

Check the username, password and full server URL, including the http:// or https:// prefix and any port. Confirm your Kemo account is active. If the error remains, contact Kemo support and share the error message, not your password.
